# Security policy

Report suspected vulnerabilities privately to **twbdavis@gmail.com**. Include
the affected version, reproduction steps, and impact. Do not send credentials,
personal records, or private documents. Please avoid public issues for unpatched
vulnerabilities.

This is a personal project maintained on a best-effort basis. Security fixes target
the latest source on the main branch; older versions may need to be upgraded.

See the README for storage locations and application limitations. Keep local data
and credentials out of screenshots, logs, and bug reports.
