# Portfolio Tracker frontend

React and TypeScript UI hosted by the Windows application's WebView2 shell.

Use the [repository setup](../README.md#build-from-source) and
[development guide](../docs/development.md) to connect to the authenticated local API.
A standalone Vite page needs the session token and API base URL from the shell.

From this directory: `npm test`, `npm run lint`, and `npm run build`.
